# Vigilabebé

Cámara de bebé por la web (WebRTC con PeerJS + TURN). Todo está en `index.html`.

1. Móvil junto al bebé: abrir la web → "CÁMARA". Mejor enchufado.
2. Tu móvil: abrir la web → "VER AL BEBÉ" (o abrir el enlace con `?ver`).

Ahorro de batería en la cámara: se apaga sin monitores, pantalla en negro automática,
perfiles de calidad con límite de bitrate y modo solo audio.
